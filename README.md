# cadastro-jogos-python
# Cadastro de Jogos em Python

Projeto desenvolvido em **Python** para praticar manipulação de arquivos e organização de dados.

O programa permite cadastrar jogos e seus respectivos videogames, armazenando as informações em um arquivo de texto.

## 🎮 Funcionalidades

* Criar o arquivo de dados automaticamente
* Cadastrar jogos
* Associar cada jogo a um videogame
* Listar os jogos cadastrados
* Validar opções do menu
* Encerrar o programa

## 📚 Conceitos praticados

* Funções
* Estruturas condicionais
* Estruturas de repetição
* Manipulação de arquivos
* `try`, `except`, `else` e `finally`
* Leitura e escrita de arquivos
* Validação de entrada
* Organização de dados

## 🛠️ Tecnologia

* Python
